# Phys-Lab 公開前チェックリスト

- 制定日: 2026-09-16
- 用途: 新規教材、ページ改修、PDF 差し替え、公開前レビュー

変更規模に応じて該当項目を使う。確認できない項目はチェックせず、完了報告で「未確認」とする。Codex の確認後も、物理内容、教材としての難易度、表現、UI の直感性、公開可否は人間が最終確認する。

## 1. 作業範囲と差分

- [ ] `dev` ブランチで作業している
- [ ] 依頼内容と変更対象が一致している
- [ ] ユーザーの既存変更や未追跡ファイルを上書き・削除していない
- [ ] 既存 URL を変更していない、または旧 URL の互換導線がある
- [ ] `git diff` で意図しない変更がない
- [ ] `git diff --check` が合格する
- [ ] 新しい不要ファイル、生成物、`.DS_Store`、管理用ノートが含まれていない

## 2. コンテンツとメタデータ

- [ ] ページタイトルと `h1` が内容を正しく表す
- [ ] 単元が `docs/CONTENT_POLICY.md` の分類に沿っている
- [ ] 対象レベル（物理基礎・物理・発展）が文字で表示されている
- [ ] 教材形式（読む・見る・動かす・調べる）が分かる
- [ ] 1〜2文の概要がある
- [ ] 更新日が `YYYY-MM-DD` の内容更新日として正しい
- [ ] 必要な関連教材と次の学習導線がある
- [ ] 準備中の内容が利用可能な教材より目立っていない
- [ ] 高校生に分かる日本語で、不要な専門用語や英語だけの分類がない
- [ ] サイトを学校公式サイトと誤認させる表現がない

## 3. 物理内容

- [ ] 数式と変形が正しい
- [ ] 変数と記号を説明している
- [ ] 単位と次元が正しい
- [ ] 初期条件、座標軸、正方向、符号が明確である
- [ ] 前提・近似・適用範囲を説明している
- [ ] 本文、図、グラフ、数値結果が一致している
- [ ] 表示上の丸めが誤解を生まない
- [ ] 対象レベルに対して説明と難易度が適切である
- [ ] 人間が物理内容を最終確認した

## 4. シミュレーション

- [ ] 教材の目的と操作方法が分かる
- [ ] 初期値だけでも意味のある表示になる
- [ ] 入力名、単位、範囲が表示されている
- [ ] 再生・一時停止・リセット等が期待通り動く
- [ ] 同じ操作を繰り返しても状態が破綻しない
- [ ] 0、最小値、最大値、境界値を確認した
- [ ] 不正値、空入力、急な連続操作で破綻しない
- [ ] 主要結果が Canvas 外の HTML にも表示される
- [ ] Canvas のサイズ・解像度が各画面幅で適切である
- [ ] モデルの前提（空気抵抗、重力加速度、質点等）が明示されている
- [ ] JavaScript のコンソールエラーがない

## 5. HTML とアクセシビリティ

- [ ] `<html lang="ja">` がある
- [ ] `<title>` と `meta name="description"` がページ固有である
- [ ] `header`、`nav`、`main`、`section`、`article`、`footer` を適切に使っている
- [ ] `h1` は原則1つで、`h1` → `h2` → `h3` の階層が飛んでいない
- [ ] ナビゲーションに分かる `aria-label` がある
- [ ] 意味のある画像に適切な `alt` がある
- [ ] 装飾画像が読み上げ対象になっていない
- [ ] 色だけで意味や状態を伝えていない
- [ ] 文字と背景、UI 部品のコントラストを確認した
- [ ] リンク文言だけで移動先が分かる
- [ ] フォーム要素にラベルが関連付けられている
- [ ] 主要機能をキーボードだけで操作できる
- [ ] フォーカス位置が視覚的に分かる
- [ ] 読み上げ順と DOM 順が自然である
- [ ] 動きがある場合、`prefers-reduced-motion` を考慮している

## 6. レスポンシブと操作

- [ ] デスクトップ幅で表示・操作を確認した
- [ ] iPad 横相当で表示・操作を確認した
- [ ] iPad 縦相当で表示・操作を確認した
- [ ] スマートフォン縦相当で表示・操作を確認した
- [ ] スマートフォン横相当で表示・操作を確認した
- [ ] Safari で確認した
- [ ] Chrome で確認した
- [ ] 必要に応じて Edge で確認した
- [ ] ページ全体に横スクロールが発生しない
- [ ] 200% 拡大または大きな文字でも主要内容を利用できる
- [ ] ボタン、リンク、スライダーをタッチで操作しやすい
- [ ] ホバーしないと得られない重要情報がない
- [ ] sticky ヘッダーが見出しやフォーカス要素を隠さない

## 7. リンクと回帰

- [ ] 追加・変更したローカルリンクが実在する
- [ ] トップ、単元一覧、教材一覧へ戻れる
- [ ] 外部リンクが到達可能で、意図した内容である
- [ ] 新しいタブで開く外部リンクに `rel="noopener noreferrer"` がある
- [ ] GitHub Pages の `/Phys-Lab/` 配下で相対パスが解決する
- [ ] 404 ページから主要導線へ復帰できる
- [ ] 既存のトップ、スライド、ノート、リンク、ツール各ページを確認した
- [ ] 既存の投射運動シミュレーションを操作確認した

## 8. PDF

- [ ] 表示題名、PDF 内タイトル、ファイル内容が一致する
- [ ] ファイル名が公開用として説明的である
- [ ] Author / Creator / Producer 等のメタデータを確認した
- [ ] 個人情報、学校情報、内部 URL、コメント、添付ファイルがない
- [ ] フォント、画像、数式が崩れず表示される
- [ ] ページサイズ、向き、余白、改ページが意図通りである
- [ ] リンクがある場合は動作する
- [ ] モバイル通信に対して容量が過大でない
- [ ] 差し替え後も既存 URL が有効である

## 9. 著作権・プライバシー・セキュリティ

- [ ] 本文、画像、図、問題文を公開する権利がある
- [ ] 引用には必要性があり、範囲と出典が適切である
- [ ] 第三者素材の利用条件と帰属表示を確認した
- [ ] 生徒氏名、クラス、成績などの個人情報がない
- [ ] 学校名、学校メール、校内 URL、Teams / SharePoint URL、校内 IP がない
- [ ] API キー、トークン、パスワード、秘密鍵、`.env` がない
- [ ] HTML コメント、JavaScript、ファイル名、PDF メタデータも確認した
- [ ] ライセンス表示が素材とリポジトリの方針に矛盾しない

## 10. パフォーマンスと依存関係

- [ ] 画像を表示寸法と用途に合う形式・容量にした
- [ ] 不要な JavaScript、CSS、外部 CDN、Web フォントを追加していない
- [ ] Canvas を必要以上の解像度で描画していない
- [ ] ページ読み込み時に大きなレイアウトずれがない
- [ ] 低速回線でも主要テキストとナビゲーションを利用できる

## 11. 公開直前・公開後

- [ ] 変更内容、変更ファイル、テスト結果を報告した
- [ ] 未確認環境と既知の問題を報告した
- [ ] 人間が実ページ、表現、難易度、公開可否を確認した
- [ ] `main` へ反映する差分がレビュー済みである
- [ ] GitHub Pages の Enforce HTTPS が有効である
- [ ] 公開後の主要 URL と更新対象ページを確認した
- [ ] 問題発生時に戻す対象コミットを把握している
