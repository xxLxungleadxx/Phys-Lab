# Phase 5 既存教材の関連付け・検証結果

- 作業日: 2026-09-18
- ブランチ: dev

## 変更概要

既存の10ページ（スライド、ノート、リンク集、ツール総合一覧、分野別ツール一覧5件、投射運動）を単元優先の情報構造へ関連付けた。Phase 3・4の未コミット変更を維持している。

- ヘッダーの単元・教材形式・使い方・更新情報の導線を全16ページで統一
- 形式別一覧に5つの単元への切り替えを追加
- 分野別ツール一覧に対応する単元ページへのリンクを追加
- ツール総合一覧の各分野カードから、その単元の全教材へ接続
- スライド6件、ノート9件、投射運動1件の既存カードに対象レベル表示と単元・レベル・形式の分類を追加
- スライド一覧、ツール総合一覧、力学ツール一覧の見出し階層の飛びを解消
- リンク集の分類を「物理」「数学」に変更
- 既存ページのフッターにも個人運営の公開教材サイトである旨を明示
- 投射運動に対象レベル、モデルの前提、教材案内更新日、関連教材、Canvasの代替説明を追加
- 共通CSSに新しい導線のタップ領域、フォーカス表示、狭い画面でのナビゲーションの折り返しを設定

投射運動の計算処理、アニメーション処理、入力範囲は変更していない。PDF本文・ファイル名・内容改訂日は変更していない。案内更新日をPDF改訂日と同一視せず、不明な改訂日を推測して付けていない。
