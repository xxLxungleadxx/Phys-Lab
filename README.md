# Phys-Lab

高校物理を「読む・見る・動かす」ことで学べる、個人運営の公開教材サイトです。高校生の復習・自学を中心に、物理の現象を図・グラフ・シミュレーションで確かめたい人を対象にしています。学校公式サイトではありません。

[公開サイトを開く](https://xxlxungleadxx.github.io/Phys-Lab/)

## サイト構成

トップページでは「単元から探す」を優先し、「教材の種類から探す」も用意しています。

- 単元：力学・熱・波・電磁気・原子
- 教材：PDFノート、授業用スライド、動かせる教材、参考リンク
- シミュレーション：投射運動（空気抵抗を無視し、同じ高さに着地するモデル）

未公開の教材は準備中として区別しています。既存のPDFと公開URLを維持しながら、教材を少しずつ拡充します。

## 技術構成

GitHub Pagesで配信する静的サイトです。Vanilla HTML / CSS / JavaScriptを使い、共通スタイルは `style.css`、投射運動の描画はCanvas APIで実装しています。公開サイトの動作にNode.jsやビルド処理は不要です。

主要ディレクトリは `mechanics/`、`thermodynamics/`、`waves/`、`electromagnetism/`、`atomic/`（単元）、`note/`、`slide/`、`tools/`、`link/`（教材形式）です。

## ローカル開発

CLI検証にはNode.js 22.22以降の22系、または24.8以降とnpmを使用します。CIは24系です。

```sh
npm ci
npm run test:install-browsers
npm run serve:test
```

サーバー起動後、`http://127.0.0.1:4173/Phys-Lab/` で確認できます。終了はCtrl+Cです。GitHub Pagesと同じプロジェクトパスで、404の復帰導線も確認できます。

```sh
# サーバーを停止してから実行（テスト側が自動起動・終了）
npm test

# 手早いChromiumデスクトップ検証
npm run test:smoke

# HTML・CSS・JavaScriptと検証コードの単体テスト
npm run test:static

# 外部リンクの到達確認（ネットワークが必要）
npm run test:external-links
```

Playwrightとaxeは開発専用で、公開HTMLには読み込ませません。自動検査は実機・スクリーンリーダー・物理内容の人間による確認の代替ではありません。検証文書・結果・レポートはローカル管理とし、Gitには含めません。

GitHub Actionsでは `dev`・`main` へのpushとPRで静的検査・物理検証・ブラウザ検証を実行する設定です。外部リンク確認は別ワークフローで毎月・手動実行します。結果レポートのアップロードや自動公開は行いません。

## 開発方針

- `dev` は開発、`main` は公開用。人間が確認してから公開へ反映します。
- 単元から探しやすく、対象レベルと目的が分かる教材を優先します。
- PC・iPad・スマートフォン、キーボード操作、動きを抑える設定を考慮します。
- 既存URLを維持し、不要なフレームワークや外部依存を増やしません。
- 物理内容・難易度・公開可否は人間が最終判断します。

詳細は [設計方針](docs/DESIGN.md)、[コンテンツ公開方針](docs/CONTENT_POLICY.md)、Codex向けの [開発ルール](AGENTS.md) を参照してください。
