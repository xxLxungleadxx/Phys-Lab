# Phys-Lab 設計方針

- 制定日: 2026-09-16
- 対象: 情報設計、URL、ナビゲーション、共通 UI
- 基準: `Phys-Lab_Codex_Development_Guide.md`、`docs/PHASE1_AUDIT.md`

## 1. 設計目標

Phys-Lab を、ファイル形式別の教材置き場ではなく、高校物理の学習入口として設計する。利用者が「どの単元を学びたいか」から入り、同じ単元の読む・見る・動かす教材を行き来できる状態を目指す。

設計上の優先順位は次の通り。

1. 単元から探せる
2. 対象レベルと教材の目的が分かる
3. 関連教材へ移動できる
4. 端末や入力方法に依存せず利用できる
5. 公開済み URL を維持する

## 2. 情報構造

### 2.1 第1軸: 単元から探す

| 表示名 | 識別子 | 単元ページ |
| --- | --- | --- |
| 力学 | `mechanics` | `/mechanics/` |
| 熱 | `thermodynamics` | `/thermodynamics/` |
| 波 | `waves` | `/waves/` |
| 電磁気 | `electromagnetism` | `/electromagnetism/` |
| 原子 | `atomic` | `/atomic/` |

単元ページは教材形式を横断し、次の順で構成する。

1. 単元名、概要、対象範囲
2. 対象レベル別の案内
3. 「読む」PDF ノート
4. 「見る」授業用スライド
5. 「動かす」シミュレーション
6. 関連する外部リンク

教材がない区分は大量の「準備中」カードで埋めず、短い案内にとどめる。

### 2.2 第2軸: 教材の種類から探す

既存の形式別ページを維持する。

| 表示名 | UI 上の動詞 | パス |
| --- | --- | --- |
| PDF ノート | 読む | `/note/` |
| 授業用スライド | 見る | `/slide/` |
| 動かせる教材 | 動かす | `/tools/` |
| リンク集 | 調べる | `/link/` |

形式別ページは補助導線であり、トップページでは単元導線の後に配置する。

## 3. URL 方針

### 3.1 基本規則

- パスは英小文字の英数字とハイフンで構成する。
- 単元ページには末尾スラッシュ形式を使う。
- `page1.html` や `tool01.html` のように内容が分からない名前を使わない。
- URL は公開後に原則変更しない。
- GitHub Pages のプロジェクトパス `/Phys-Lab/` でも成立する相対リンクを使う。

### 3.2 段階的な移行

現行 URL は公開済み資産として維持する。Phase 3〜6 では、既存ページを削除・移動せず、新しい単元ページから現行教材へリンクする。

特に `/tools/mechanics/projectile.html` は当面そのまま利用する。将来 `/mechanics/projectile/` のような学習者向け URL へ移す場合は、同じ変更内で旧 URL に互換ページまたはリダイレクトを用意し、ブックマークと外部リンクを壊さない。移行判断は個別タスクとして行う。

### 3.3 既存 URL の役割

- `/tools/{subject}/` は動かせる教材だけを一覧する形式別ページとして残す。
- `/{subject}/` は読む・見る・動かすを統合する単元ページとする。
- `/slide/`、`/note/`、`/link/` は既存 URL として維持する。
- 未存在 URL には `404.html` からトップ、単元、教材形式への復帰導線を出す。

## 4. グローバルナビゲーション

主要ナビゲーションは、狭い画面でも項目過多にならないよう、次を基本とする。

- Phys-Lab（トップ）
- 単元から探す
- 教材から探す
- このサイトについて

ページ内リンクが使えるトップページでは各セクションへ、下層ページではトップページの該当セクションまたは代表一覧へ接続する。単元5件と教材形式4件をすべて常時ヘッダーへ並べる必要はない。

各ページには現在地が分かるページタイトルを置く。深い階層の教材ページには、トップまたは親一覧へ戻れる導線を本文上部か下部に用意する。

## 5. ページ設計

### 5.1 トップページ

推奨順序は次の通り。

1. サイト名と一文の説明
2. 単元から探す
3. 教材の種類から探す
4. サイトの使い方
5. 最近追加・更新された教材
6. 個人運営であることを明示したフッター

大きな「更新予定」領域は置かない。予定を掲載する場合は短くし、現在使える教材より目立たせない。

### 5.2 単元ページ

- `h1` は単元名とする。
- 冒頭で学ぶ内容を高校生向けの言葉で説明する。
- 教材カードに題名、レベル、形式、説明を表示する。
- 同じ教材をレベル別・形式別に重複表示する場合も、リンク先は同じ正規 URL にする。
- 教材がない場合でも、存在しないリンクは作らない。

### 5.3 教材ページ

- `h1` は教材名とする。
- 対象レベル、概要、更新日を本文から確認できるようにする。
- シミュレーションでは操作条件、結果、モデルの前提を近接して表示する。
- 関連教材は本文の後に配置し、次の学習行動を示す。

### 5.4 一覧カード

カード全体の情報順序を原則として統一する。

1. 対象レベルの文字ラベル
2. 教材名
3. 一文の説明
4. 教材形式または補足
5. 明確なリンク文言

「こちら」「詳細」のようにリンク先が分からない文言を避ける。カード全体をリンクにする場合でも、フォーカス表示と読み上げ順を確認する。

## 6. 表示と言葉

- 基本言語は日本語とし、高校生が理解できる表現を使う。
- UI では「読む」「見る」「動かす」「調べる」を優先し、不要な Web 専門用語や英語だけの分類を避ける。
- 対象レベルは「物理基礎」「物理」「発展」と文字で表示する。
- 日付は本文では `YYYY年M月D日`、機械可読値やメタデータでは `YYYY-MM-DD` を基本とする。
- 装飾用の数式も高校物理との関連が分かるものを使う。

## 7. ビジュアルとレスポンシブ

- 既存の落ち着いた紙色、緑を中心とする配色、角丸カードを基本にする。
- トップページのヒーロー画像領域は、教材への導線を早く見せるため、デスクトップで約210px、860px以下で約190pxを基準とする。
- CSS カスタムプロパティを色、余白、幅、影の共通値に使う。
- 色は補助表現とし、ラベル本文を省略しない。
- 本文幅と行長を制限し、長文を読みやすくする。
- タップ対象は隣接要素との間隔を確保し、タッチ操作しやすくする。
- 860px 前後と 520px 前後の既存ブレークポイントを出発点とし、実内容に応じて調整する。
- ページ全体の横スクロールは禁止する。横幅が必要な表や可視化は、内容を損なわない縮小または局所的な処理を行う。

## 8. 共通レイアウトの管理

現段階ではビルド工程を導入せず、HTML / CSS / JavaScript の静的構成を維持する。ヘッダー、ナビゲーション、フッターを変更した場合は全 HTML を検索し、同一内容と相対パスを確認する。

情報構造が安定した後、共通変更の反復が保守上の問題になった時点で Jekyll、Eleventy、Astro などを比較する。導入する場合も、公開 URL と生成結果を先に固定し、フレームワーク導入自体を目的にしない。

## 9. 今後の設計判断

次は Phase 2 では実装せず、該当フェーズで判断する。

- Phase 3: トップページの具体的な文言と最近の更新内容
- Phase 4: 各単元ページに載せる教材の割り当て
- Phase 5: 既存一覧・教材ページを単元ページへ関連付け、必要なメタデータを反映する
- Phase 6: 実機またはブラウザでのレスポンシブ・アクセシビリティ検証
- Phase 7 以降: 404、OGP、README、自動検証、ライセンス、公開運用の整備

## 10. Phase 4 の教材割り当て

2026年9月18日に5つの単元ページを追加した。トップページの単元カードは、直接のPDFリンクから単元ページへのリンクに切り替える。

| 単元 | 読む | 見る | 動かす |
| --- | --- | --- | --- |
| 力学 | 第1章 力学 | 力学基礎編 1・2 | 投射運動 |
| 熱 | 第2章 熱 | 熱力学基礎編 | 未公開 |
| 波 | 第3章 波 | 波動基礎編 | 未公開 |
| 電磁気 | 第4章 電磁気 | 電磁気基礎編 | 未公開 |
| 原子 | 第5章 原子 | 未公開 | 未公開 |

共通の補助導線として、公式まとめ、物理の考え方、ノート一覧、リンク集を案内する。単元ページの更新日は表示するが、既存PDFの内容改訂日とは明確に区別する。既存の形式別一覧・シミュレーションから単元への戻り導線は Phase 5 で整備する。

## 11. Phase 5 の関連付け

2026年9月18日に既存の形式別一覧・ツールページから単元ページへの導線を追加した。

- 全16ページの主要ナビゲーションを単元・教材形式・使い方・更新情報に統一
- スライド、ノート、リンク集、ツール総合一覧に単元への切り替えを追加
- 各分野のツール一覧から、その単元の読む・見る・動かす一覧へ接続
- 既存のPDF・投射運動カードに単元、対象レベル、教材形式を付与
- 投射運動に力学ページ、ノート、スライドへの関連導線とモデルの前提を追記

既存PDFの改訂日は不明なため、案内を変更した日をPDFの改訂日として記録しない。投射運動の案内更新日は表示するが、JavaScript・入力範囲は維持する。対象レベルの割り当ては公開前に人間が確認する。
